A deadpan weather forecast for a city that does not exist — a [make.fun](https://make.fun/bounty/u-coral-ibis-18-deadpan-forecasts-for-cities-that-do-151d4d8c) entry.

## Run

```sh
python3 main.py
```

It writes a single forecast line (at most 160 characters) to `/output/entry.txt`.
No network, no input, fully deterministic.
